# Toksave

Русскоязычный веб-интерфейс для локального TikTok-загрузчика. Поле ссылки, вставка из буфера, проверка адреса, состояние загрузки, отмена запроса, предпросмотр MP4, сохранение файла и последние восемь видео.

## Запуск через Docker Compose

Нужен Docker с Linux-контейнерами и Docker Compose v2+. Из папки проекта:

```powershell
docker compose up -d --build
```

Откройте http://127.0.0.1:8000. На этой машине предыдущая настройка прокси сохранена в локальном `.env`; в чистом клоне прокси по умолчанию не используется. Для настройки скопируйте `.env.example` в `.env` и измените значения. `.env` не попадает в Git или Docker image. `.env` автоматически читает Compose; для запуска Python напрямую передайте нужные значения как переменные окружения.

```powershell
Copy-Item .env.example .env
docker compose up -d --build
docker compose ps
docker compose logs -f
docker compose down
```

Не перезаписывайте существующий `.env`, если в нём уже указан ваш прокси. Для другого порта установите `PORT=8010` в `.env`. По умолчанию порт опубликован только на `127.0.0.1`; для доступа с других устройств задайте `BIND_HOST=0.0.0.0`.

Видео сохраняются в именованном volume `downloads` и остаются после обычного `docker compose down`. Команда `docker compose down -v` удаляет и volume с видео.

Необязательные cookies: экспортируйте cookies TikTok в Netscape-формате в `cookies/tiktok.txt` и задайте `TIKTOK_COOKIES_FILE=/run/cookies/tiktok.txt` в `.env`. Эта папка подключается только для чтения и исключена из Git и сборки. Профиль Firefox на Windows контейнеру не нужен.

### Многоэтапная сборка

`builder` собирает wheels зависимостей. `runtime-base` устанавливает зависимости и FFmpeg и создаёт пользователя без прав root. `test` запускает тесты. Финальная стадия `runtime` копирует проверенный код без тестов, кешей, локального окружения и скачанных видео. Если тесты упадут, финальный образ не соберётся. Контейнер проверяет `/health`; корневая файловая система в Compose доступна только для чтения, данные пишутся в volume, временные файлы — в `/tmp`.

Отдельные команды:

```powershell
docker compose config --quiet
docker build --target test -t tiktok-downloader:test .
docker build --target runtime -t tiktok-downloader:local .
```

### Чистый Git

`.gitignore` исключает `.venv`, кеши Python, видео, cookies, `.env`, временные файлы и старые локальные заготовки. `.dockerignore` допускает в контекст сборки только Dockerfile, исходники и тесты, затем исключает данные и кеши внутри них. Файлы на вашем диске сохраняются.

В папке проекта на момент подготовки нет `.git`. Для нового репозитория:

```powershell
git init
git add .
git status --short
git commit -m "Add frontend and multi-stage Docker setup"
```

В репозиторий попадает `.env.example` без паролей. Не добавляйте файлы, исключённые `.gitignore`, через `git add -f`.

## Запуск в Windows без Docker

Из папки проекта:

```powershell
.\start.ps1
```

Откройте http://127.0.0.1:8000. Остановить сервер: `Ctrl+C`.
Для другого порта: `.\start.ps1 -Port 8010`.

Если PowerShell запрещает запуск скрипта, можно запустить напрямую:

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --app-dir src --host 127.0.0.1 --port 8000
```

Для нового окружения:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r src\requirements.txt
```

## Как устроено

`src/static/` содержит HTML, CSS и обычный JavaScript. Сборка и Node.js не требуются. FastAPI отдаёт интерфейс на `/`, статические файлы на `/static`, а видео — через существующий `POST /api/tiktok`. Тело запроса остаётся JSON-строкой со ссылкой.

История хранит только ссылки и сведения о файлах в localStorage этого браузера. Готовые файлы доступны для повторного сохранения до перезагрузки вкладки. После перезагрузки кнопка «Загрузить снова» подставляет ссылку в форму. Очистка истории не удаляет скачанные файлы на диске.

Кнопка «Отменить» прекращает ожидание и передачу в браузере; уже начавшаяся задача yt-dlp на сервере может продолжиться. Пока сервер получает видео, отображается ожидание; процент передачи показывается только при наличии размера файла в ответе.

Реальное скачивание использует `TIKTOK_PROXY` (необязательно), `TIKTOK_COOKIES_FILE` (необязательно) и `TIKTOK_DOWNLOAD_DIR` (папка видео). Без переменных используются прямое соединение, отсутствие cookies и папка `src/downloaded_tiktoks`. Если источник, прокси или cookies недоступны, интерфейс показывает сообщение об ошибке. Качество определяется доступным исходником и настройкой `format: best` загрузчика.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

Тесты подменяют скачивание и проверяют контракт API, ошибки и отдачу фронтенда без обращения к TikTok. Дополнительные тестовые зависимости не требуются.
